
# SIGHTMATE

An AI-powered, accessible STEM learning platform for visually impaired and low-vision students.

## Vision
To make STEM education accessible through hybrid spatial learning, voice interaction, and curriculum-grounded AI.

## Initial MVP
- Karnataka State Board – Class 10
- English and Kannada
- Biology: Human Heart and Blood Circulation
- Mathematics: Surface Areas and Volumes

## Technology Stack
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Spatial UI: SVG + Three.js
- Database: PostgreSQL
- AI: LLM + RAG

## Team
Five-member development team.

## Accessibility
Visual and nonvisual spatial navigation with adaptive accessibility settings.
